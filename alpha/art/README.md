# Syndicate Tycoon generated art

Photorealistic game and website imagery in the project's corporate-noir palette: charcoal blacks, cyan-blue glass light, restrained amber practical light, and sparse red accents.

Asset groups:

- `backgrounds/` — page and landing backgrounds
- `workers/` — two portraits per company worker role
- `crew/` — one portrait per Syndicate crew role
- `products/` — product artwork
- `hardware/` — infrastructure artwork
- `research/` — flagship research artwork
- `gear/` — Syndicate equipment artwork
- `security/` — physical and digital security upgrades
- `missions/` — operation artwork
- `company/` — rags-to-riches company-premises progression

Generated images contain no baked-in labels, brands, logos, or watermarks. UI copy remains live HTML for accessibility and localisation.

Company premises currently include `basement.webp`, `garage.webp`, `spare-room.webp`, `apartment.webp`, `rented-space.webp`, `office-floor.webp`, `headquarters.webp`, and `campus.webp`.

Shared shell artwork includes `backgrounds/main-webpage.webp` behind the site and `backgrounds/masthead-skyline.webp` behind the logo. The default Company overview uses the shallow `company/founder-desk.webp` detail banner.
